# @ceibo/cli

CLI de administración (`ceibo`) sobre el store: usuarios, canales, repos, reporte de gasto.

- **Depende de (interno):** oauth, store, wikis
- **Consumido por:** nadie (binario de admin)

## Scope

Estás trabajando en `@ceibo/cli`. Editá **solo** dentro de `packages/cli/`. Si el
cambio necesita tocar otros paquetes, pará: declará el scope cruzado en
`.claude/active-scope` (ej. `cli <otro>`) o vacialo si el cambio cruza a propósito —
no edites otros paquetes "de paso". El guard de scope lo enforcea. Ver el `CLAUDE.md` raíz.

# @ceibo/agent

Cliente de Managed Agents cloud: la sesión como stream bidireccional sin turnos. Channel-agnostic.

- **Depende de (interno):** nada (hoja)
- **Consumido por:** channels, oauth, gateway, web-server

## Scope

Estás trabajando en `@ceibo/agent`. Editá **solo** dentro de `packages/agent/`. Si el
cambio necesita tocar otros paquetes, pará: declará el scope cruzado en
`.claude/active-scope` (ej. `agent <otro>`) o vacialo si el cambio cruza a propósito —
no edites otros paquetes "de paso". El guard de scope lo enforcea. Ver el `CLAUDE.md` raíz.

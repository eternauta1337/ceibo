# @ceibo/web

UI web de ceibo (managed-ui): círculo push-to-talk + espacio de wiki. React + Vite, build estático.

- **Depende de (interno):** nada (hoja)
- **Consumido por:** nadie (se sirve buildeada)

## Scope

Estás trabajando en `@ceibo/web`. Editá **solo** dentro de `packages/web/`. Si el
cambio necesita tocar otros paquetes, pará: declará el scope cruzado en
`.claude/active-scope` (ej. `web <otro>`) o vacialo si el cambio cruza a propósito —
no edites otros paquetes "de paso". El guard de scope lo enforcea. Ver el `CLAUDE.md` raíz.

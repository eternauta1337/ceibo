# @ceibo/wikis

Substrato de wikis: crea/hostea las wikis de usuarios (repos git) y mintea tokens efímeros scoped. Backend hoy: GitHub App.

- **Depende de (interno):** nada (hoja)
- **Consumido por:** cli, gateway, web-server

## Scope

Estás trabajando en `@ceibo/wikis`. Editá **solo** dentro de `packages/wikis/`. Si el
cambio necesita tocar otros paquetes, pará: declará el scope cruzado en
`.claude/active-scope` (ej. `wikis <otro>`) o vacialo si el cambio cruza a propósito —
no edites otros paquetes "de paso". El guard de scope lo enforcea. Ver el `CLAUDE.md` raíz.

Con `debugMode` prendido, la web muestra un readout de debug del pipeline de grabación: tras cada grabación aparece una línea compacta con el estado del track/contexto/unmute, el pico de nivel del mic, los chunks/bytes que entregó el recorder y la rama final (enviada o descartada y por qué) — para diagnosticar en el dispositivo dónde se rompe la captura. Sin efecto con debug apagado.

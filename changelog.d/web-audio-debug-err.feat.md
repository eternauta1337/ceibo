El readout de debug de grabación (detrás de debugMode) ahora muestra el DETALLE del fallo de getUserMedia cuando la captura no arranca: el nombre del error (y su mensaje recortado), el camino tomado (cached / fresh / fresh-default), si esperó una adquisición en vuelo (waited ms) y si el getUserMedia corrió dentro del gesto del usuario (gesture=active|stale|n/a). Sin efecto con debug apagado.
